:::caution[En desarrollo]

- **Stack**: React Native con Expo y TypeScript.
- **Diseño**: los mismos `@inzumer/tokens` que la web, así una app mobile y una web se ven igual.
- **Storybook**: [ui-native.inzumer.com](https://ui-native.inzumer.com), con la versión web de los
  componentes para revisarlos sin un teléfono.
- **Estructura**: igual que la librería web: [atomic design](/practicas/estructura/), una carpeta
  por componente con su barrel, test, historia y README.
